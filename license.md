## 🔧 How to Use (Step-by-Step)

### Step 1: Download and Extract

*   Download `thingiverse-python.zip` from the button below
*   Extract to a folder of your choice

### Step 2: Install Dependencies

*   Open terminal/command prompt in the extracted folder
*   Run `pip install -r requirements.txt`
*   Wait for all packages to install

### Step 3: Use the Downloader

*   Run `python download.py --url "https://www.thingiverse.com/thing:12345"`
*   Or use batch mode: `python batch.py --list models.txt`
*   Customize with filters: `--format stl --output ./models`

### Step 4: Write Custom Scripts

*   Import the library: `from thingiverse import ThingiverseAPI`
*   Use the API for custom automation
*   See examples in the `examples/` folder
